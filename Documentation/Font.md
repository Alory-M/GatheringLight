# 字体来源

- 字体：Noto Sans SC，Google Fonts 仓库 `ofl/notosanssc/NotoSansSC[wght].ttf`。
- 来源：https://github.com/google/fonts/tree/main/ofl/notosanssc
- 许可：SIL Open Font License 1.1，完整文本在 `Assets/Resources/NotoSansSC-OFL.txt`。
- 本项目使用 FontTools 4.61.1 将可变字体固定为 `wght=500`，保留中文字符集，减少旧版 Unity 字体导入的兼容性风险。
- 不使用其保留字体名 Source，不单独销售字体。
