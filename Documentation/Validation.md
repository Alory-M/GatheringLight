## Unity / 手机验收步骤

1. 使用指定 Unity 打开项目，确认整个 Game 视图自动选中 Pixel Moments Portrait 9:16（900×1600），即使进入 Play 前手动选择横屏，进入时也应恢复。确认主页三个关卡、手机竖屏、中文和像素预览显示正确。
2. 逐关检查 15×15 棋盘、5×5 分区线、行列线索全部可见；检查主页、帮助、棋盘和通关都占用同一竖屏画面，背景满屏；在刘海屏检查安全区，桌面确认整个窗口为竖屏。
3. 用鼠标／单指按住横划一行、纵划一列，确认中间格无遗漏、斜移不串行、回划不重复扣值、第二根手指不接管笔画；移出棋盘后释放，再起一笔正常。
4. 测试三种工具切换、滑动擦除、点重置后继续滑动、滑动时失焦，确认不残留旧手势。
5. 首关题目首行前五格均为空白。依次错误填色应扣至 0 后立即锁定；继续滑动不能再修改。重置恢复全部格子和 5 点推理值。
6. 全部填色格正确但未打叉：不能通关。完成所有 225 格后逐行显色，叉号与格缝消失，显示完整彩色画。
7. 前两关点击下一关：新棋盘清空、推理值 5；第三关完成后提示返回主页，点击显示收集勾选，并可重新选关。
8. 通关状态重置不可用；揭图途中返回主页、重新入关后无旧动画覆盖。
9. 安装对应 Build Support，分别运行 Android / Windows 构建入口，在独立播放器或真机重复关键路径。
