# 当前实现约定

策划依据为用户提供的策划案和后续修改。最新规则覆盖早期的「锁行列滑动」「全部 225 格包括叉号才通关」「统一黄色填色」。

## 图像与输出

整个输出为 9:16 竖屏。Unity Editor 加载项目、切换构建平台、进入 Play 时，将实际 Game View 渲染目标设为 900×1600；桌面启动时也设置整个窗口。所有页面共用全屏 Canvas，背景铺满屏幕，UI 根节点拉伸至安全区。

Game View 使用经 Unity 2022.3 源码核对的内部 `SetCustomResolution` 反射方法，失败时提示手动选择；仍需指定中国版编辑器验证。

三幅图使用用户选定参考图：向阳花、小屋、无额外镂空的蝴蝶。`Level.cs` 保存 15×15 像素键和调色板，实时填色、彩色线索、缩略图、完成图均从该源生成。完成图用 15×15 方形像素纹理（Point 过滤），避免圆角拼接改变边缘。三个 RGB 哈希快照固定参考画作；文档 PNG 也从同一数据导出。

画风保持明快纸感，采用平面色块、细颗粒暖底，不加镜面高光或厚渐变。错误在空白处涂色会显示珊瑚错误色并扣值，避免误以为没有操作成功；正确图案格立即显示其目标色。

## 数字与通关

行列都按连续同色段生成线索，数字的底色就是该段颜色。行由左到右，列由上到下。同色两段需至少一个空格，不同色段允许相邻。颜色自动分配，玩家无需选择画笔颜色。空行／列显示 0。

彩色求解器验证三关均唯一解。二值轮廓求解器仅保留为开发诊断，不给 UI 提供彩色线索。

通关条件：每个图案格为 Filled，每个非图案格不是 Filled。空白 Unknown 或 Empty 都可接受，叉号完全可选。多涂需擦除；若推理值归零，仍须重置。进度只统计已正确填色的图案格。

前两关完成后提示下一关，最后一关提示返回主页。完成状态禁止继续标记或重置。主页可重开任一关，本次运行收集勾选不持久化。

## 自由笔画

指针坐标保留格内小数位置，按连续采样点间的真实线段遍历网格，支持任意方向和转弯，快速移动补齐路径经过的格。穿过网格交点的精确对角线只填斜向格，不扩散到只触及角点的两个旁格。

离开棋盘的线段裁剪到边界，不把外部位置直接夹到边缘，因此不会沿边缘虚画。一笔内每个格只提交一次；新笔可以重新修改。只接收一个指针，松手、失焦、换工具、重置或切页结束笔画。误涂仍逐格扣值，归零后模型拒绝所有后续提交。
