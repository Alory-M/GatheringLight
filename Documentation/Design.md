# 当前实现约定

依据用户提供的《像素拾光_游戏策划案_V1.0.docx》，以及后续修改要求。最新要求将原首关 Demo 扩展为手机 9:16、三关 15×15、彩色完整图像、滑动标记和关卡导航。

## 视觉与关卡

沿用用户最新视觉方向：明快、鲜明、避免塑料感。暖纸底与确定性细颗粒，深灰文字、平面圆角色块，不使用镜面高光或厚重立体渐变。

三幅 15×15 手绘像素图：向阳花、晴日小屋、对称蝴蝶。玩家解题时统一暖黄填色；通关揭示金黄花盘、珊瑚屋顶、蓝绿／橙黄翅纹等完整配色。完成后格子缝隙和叉号消失，像素色块拼成完整画作。`Documentation/Art/Levels.png` 是直接从关卡数据导出的画作预览，不是运行截图。

线索从二值占用自动生成，颜色不增加额外解谜规则。每题求解器枚举结果恰好一解，且无需分支搜索即可通过行列约束传播完成。更高关卡初始可确定格更少、分段更多，但仍保留纯逻辑可解性。

## 手势

删除容易误扣分的循环工具，保留明确的涂色、叉号、擦除。按下起点立即提交；首次跨到相邻格时根据位移选横／纵轴，同笔保持该行或列。跳过的中间格自动补齐，往返只提交尚未访问的格。移到棋盘外时沿选定轴限制到边缘，抬手或失焦结束手势。只接收一个活动指针。

同笔的标记工具固定。换工具、重置、切换页面会终止旧笔。错误仍逐格扣值，锁定或完成后模型拒绝后续提交；同一状态重复提交和擦除不扣值。触屏由 Unity EventSystem 转发，需实机验证。

## 流程

主页可选三关，显示本次运行的收集勾选。前两关通关后显示「下一关」，点击后以新棋盘和 5 点推理值开始；第三关通关后显示「返回主页」。揭图动画完成后再出现按钮，玩家有时间欣赏作品。顶部主页按钮可放弃当前棋盘回到主页，再选关会重新开始。

无计时、自动解题、存档、联网或强制自动跳转。本次不发布环境版本。
