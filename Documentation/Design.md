# 实现约定

策划依据：用户提供的《像素拾光_游戏策划案_V1.0.docx》。本次制作范围为文档的首关 Demo 验收项。

最新视觉要求覆盖原低饱和马卡龙方向：明快、色彩鲜明、避免塑料感。采用暖纸底、细颗粒、鲜明平面色块、圆角棋盘和深灰字色；不使用镜面高光、厚重渐变或拟物塑料材质。

交互默认直接涂色，提供叉号与擦除工具，另提供循环模式。空白需要明确打叉才能通关。未标记不扣分，只有新提交的错误填色或叉号扣分；相同状态重复点击不算新提交。错误状态保留到玩家修改或重置，错误闪烁短暂结束，不永久染红。

重置是锁定后的唯一恢复方式；完成状态下不可重置。没有自动解题或暴露正确状态的提示按钮。没有强制计时。程序合成短提示音，无背景音乐。

后续关卡、存档、设置菜单、题库工具和自动录屏不在本次 Demo 范围。Unity 实机验证的缺口见 Validation.md。
